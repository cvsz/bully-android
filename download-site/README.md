# Bully Zone APK Download Site

Static/PHP-compatible landing page prepared for InfinityFree. Upload this directory to `htdocs/`. Hosting credentials and final hostname are intentionally not committed.

`index.php` renders the release page and `releases/latest.json` supplies machine-readable metadata. APK URL, size and SHA-256 remain empty until a real signed release artifact is verified. Never publish placeholder metadata as production.
